Приложения и подключение

⚠️ Скачивайте из App Store, Google Play или официального GitHub Releases по ссылкам ниже. APK допустим только из официального GitHub Releases разработчика. Не ставьте APK из чатов и приложения-двойники — они могут украсть ключ.

🍎 iPhone — с зарубежным Apple ID

Доступность зависит от региона.

Happ — основной

v2RayTun: доступность в российском App Store ограничена; рабочая официальная ссылка пока не подтверждена.

Streisand

Streisand — только прямые ключи, ссылка-подписка не поддерживается.

Как скачать с зарубежного Apple ID:
1. Настройки → ваше имя → Медиаматериалы и покупки → Выйти (НЕ из iCloud).
2. Откройте App Store → создайте новый Apple ID: страна Казахстан или США, способ оплаты «Нет».
3. Установите приложение, затем вернитесь на свой Apple ID.
Обновления приложения приходят только под зарубежным Apple ID.

💻 Windows

Hiddify Desktop v2rayN Windows

Импорт подписки: скопируйте ссылку-подписку в кабинете или кнопкой «🔗 Все серверы» в боте. Happ, v2RayTun, Hiddify и v2rayNG: добавьте подписку по URL или из буфера обмена (названия пунктов зависят от версии). INCY: добавьте подписку по ссылке.

sing-box: Profiles → New Profile → Remote → вставьте URL подписки; требуется конфигурация JSON sing-box, а не список vless://. Совместимость текущей подписки с INCY и sing-box на устройстве не проверена.

Для Streisand скопируйте прямой ключ сервера → + → Из буфера обмена → Connect. Windows: Добавить → Из буфера обмена → Connect.
